## Full description
MatchFlow Mobile helps shooting sports competitors follow live match results, track stage performance, compare shooters, and run what-if scoring scenarios from a modern mobile interface.

### Key features
- Live match search and offline viewing
- Stage-by-stage scoring breakdown
- Side-by-side competitor comparison
- Classification tracking support
- What-if score simulation and projected standings
